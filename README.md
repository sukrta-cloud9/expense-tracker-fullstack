# Expense Tracker

A full-stack Expense Tracker application built with the MERN stack.  
The application allows users to securely manage their personal expenses, view spending analytics, and track their overall expenses through a simple and interactive interface.

---

## Features

- User registration and login
- JWT-based authentication
- Automatic login after signup
- User-specific expense data
- Add new expenses
- Edit existing expenses
- Delete expenses
- Default expense categories
- Add custom expense categories
- Edit and delete expense categories
- Total expense calculation
- Recent expenses list
- Expense analytics with pie charts
- Protected routes
- Responsive interface
- MongoDB database integration
- Deployed frontend and backend
